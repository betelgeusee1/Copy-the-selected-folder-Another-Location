# Copy The Selected Folder Another Location

This Windows Forms application copies a selected folder to a destination folder.

## Prerequisites
- .NET Framework 4.7.2 or compatible

## Building
Open the solution in Visual Studio and build the project.

## Usage
1. Click **Dosya Seç** next to *Kaynak* to choose the source folder.
2. Click **Dosya Seç** next to *Hedef* to choose the destination folder.
3. Click **Kopyala** to copy all contents.

The copy button becomes active once both paths are selected.
